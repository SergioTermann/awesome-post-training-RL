# Contributing

Thanks for helping improve **Awesome Post-Training RL for LLMs**!

## Adding a paper

1. **Fork** the repo and create a branch.
2. Add the entry to the most relevant section in [`README.md`](./README.md), keeping the existing format:

   ```markdown
   - **[Title](https://arxiv.org/abs/XXXX.XXXXX)** — Author One, Author Two, … . *Venue Year*. One-line description. · [code](https://github.com/...)
   ```

3. Rules of thumb:
   - Link the arXiv abstract (or an equivalent open link).
   - Include the **full author list** (team name for institutional mega-collaborations).
   - Show the **venue** when peer-reviewed (NeurIPS / ICML / ICLR / ACL, etc.); otherwise omit it.
   - Add a `[code]` link to an **official** implementation if one exists.
4. Submit a **pull request** with a short description of what you added.

## Improving content

- Fixing broken links, typos, or outdated venue info is always welcome.
- For reorganizing sections or adding new categories, please open an issue first to discuss.

## Style

- Keep entries in roughly chronological order within each section.
- One line per paper; keep descriptions concise and factual.
